## Official data acquisition and audit

The updated environment permits actual downloads from TRTA and the OSM API. The old TRTA proxy-denial blocker is resolved. Overpass GET and POST requests returned HTTP 406; the OSM API supplied the current full relation successfully instead.

Official packages downloaded from the public TRTA downloads page:

- GPX ZIP: 55,467 bytes; seven separate tracks, 3,299 vertices. The track ends do not join exactly. Consecutive track-end chords range from 19.95 to 190.64 m, including loop closure. These chords were not added as geometry.
- 2020 KMZ ZIP: 4,668,269 bytes; 203 trail-system features. The 99 `Trail_Type=TRT` features contain 125 line parts, 300,069 vertices, seven exact-endpoint components and branch nodes. This is a trail-system dataset requiring route selection and topology review, not a single closed GPX loop. Named roads are part of the TRT; filtering only `Name=TRT` drops required geometry.
- 2020 shapefile ZIP: 3,449,936 bytes; 203 records; NAD83 / UTM zone 11N; metadata dated 2020-12-21. Archive, record count and CRS were checked. This audit does not independently compare its coordinates to KMZ.

Hashes, direct source URLs, methodology and machine-readable metrics are in [the audit](trail-data-audit-2026-10-19.json). All 13,150 shipped route vertices were compared to existing KMZ line segments: median offset 2.27 m, 95th percentile 9.35 m, maximum 372.05 m, and 121 vertices more than 100 m away. Offsets use a local projection with roughly 0.5% projection uncertainty. This is one-way positional agreement only; it does not establish equal paths, complete coverage or field accuracy. No independent survey or physical trail validation was performed.

### Retention and remaining data work

The current OSM XML is retained under ODbL in `data/source/osm-3094865-2026-10-19.xml`, excluded from the runtime pack. Official ZIPs are retained locally in the ignored `data/source/official/` directory. Explicit redistribution terms were not found on the reviewed pages or in the archive metadata, so official archives are not committed or shipped. Public download availability does not itself supply an explicit redistribution license.

To reproduce, download the three URLs listed in the audit into `data/source/official/` using its recorded filenames, then run:

```sh
python scripts/audit-trail-data.py --official-dir data/source/official
```

The audit uses Python's standard library, checks exact source endpoints, compares only existing segments and writes a report. It does not stitch nearby coordinates, interpolate gap geometry, assign elevations or overwrite application data.

Before replacing the runtime dataset: resolve the Big Meadow connection and any official alignment differences, establish current official coverage and redistribution terms, and regenerate a versioned route with documented elevations.
